## 准确率计算方法

### Gloss 准确率

**Gloss 准确率** = 1 - WER (Word Error Rate)

WER 计算公式：
```
WER = (插入 + 删除 + 替换) / 参考序列长度
```

本次评估：
- 总编辑距离: 450
- 总参考长度: 4524
- WER = 450 / 4524 = 9.95%
- **Gloss 准确率 = 90.05%** ✅

### BLEU-4 评分

字符级 BLEU-4 评分，衡量翻译质量：
- 计算 1-gram 到 4-gram 的精确匹配
- 考虑长度惩罚 (Brevity Penalty)
- 平均 BLEU-4: 36.35%

### 句子级准确率

使用 BLEU ≥ 0.5 作为阈值：
- 高质量翻译: 145 样本 (31.94%)
- 中低质量: 309 样本 (68.06%)

## 三级翻译策略

### Tier 1: 精确匹配 (8.6%)

- 训练集查表，O(1) 查找
- 100% 准确率
- 示例: `['今天', '下雨', '爷爷', '钓', '鱼', '去', '不']` → 训练集中有完全相同序列

### Tier 2: 模糊匹配 + LLM (4.0%)

- 编辑距离 ≤1 的模糊匹配
- DeepSeek LLM 精修翻译
- 约 85% 准确率
- 示例: `['谢谢']` → 模糊匹配 + LLM 调整标点

### Tier 3: 检索增强 LLM (87.4%)

- Jaccard 相似度检索 Top-6 训练样本
- Few-shot LLM 翻译
- 约 60% 准确率
- 示例: `['怀孕', '去', '抽血', '天', '2']` → LLM 翻译为 "怀孕后去抽血，第二天拿报告。"
